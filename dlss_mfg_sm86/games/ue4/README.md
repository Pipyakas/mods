# UE4 games

Unreal Engine 4.22+ games integrate DLSS-G through the same NVIDIA Streamline
plugin as UE5 games, so the [UE5 notes](../ue5/README.md) apply unchanged: where
the files go, Unreal detection, the Streamline runtime version table and the FG
switch. The differences are cosmetic: UE4 keeps its user settings under
`Saved\Config\WindowsNoEditor` instead of `Saved\Config\Windows`.
